About NOIRADIX Studio v2.0.0 PIX2 1.1
Live Pipeline Preview

Free, Client-Side Pixel Art Editor & 1-Click Unity 2D Pipeline

Built by a solo indie developer to eliminate the repetitive 15-minute bottleneck between drawing a spritesheet and wiring up walking animations in Unity during game jams. Zero install, zero accounts, pure Vanilla JS.

NEW SIBLING APP

NOIRADIX PixelArt

Dedicated 2D pixel art editor & live bi-directional PIX2 source code synchronizer. Draw freely up to 1024×1024 with zero accounts, zero install!

Launch App
1-Click Unity 2D Export

Generates anti-bleed padded atlas (.png) + C# importer script. Auto-slices sprites & sets up Animator Controllers in seconds.

Real-Time Directional Preview

Instant 4-dir & 8-dir canvas player. Scrub timeline, preview locomotion live, and adjust FPS before exporting.

Coordinate-Based DSL (.pix2)

Crisp text-coordinate format designed for LLMs (ChatGPT, Claude) with symmetry math, eliminating diffusion blur.

100% Client-Side & Offline

Runs locally in your browser. Works offline, respects your privacy, and accesses local files directly via File System API.
