# PIX2 Compatibility & Interoperability Specification

## 1. Backwards Compatibility Standards
- **Version Guarantee:** All PIX2 1.0 parsers must safely parse documents adhering to the 1.0 specification.
- **Legacy Grid Aliases:**
  - Files generated by older versions containing standard `cell_0_0` to `cell_R_C` IDs are automatically normalized with explicit `row: R, col: C`.
  - Files created by third-party LLMs containing custom cell IDs (e.g. `reaper_down_0`) and `grid_pos: r,c` directives are resolved without data loss or UI lockout.

## 2. Syntax Flexibility & Compact Serializer
- **Command Aliases:**
  - `pixel x,y color` is equivalent to `p x,y color`.
- **Row-Grouped Multi-Pixel Declarations:**
  - The compact serializer emits multiple pixels per line:
    `pixel 4,0 1 pixel 5,0 1 pixel 6,0 1`
  - Reduces file size by up to **84%** (from 2,626 lines to ~410 lines) while preserving 100% of rendered pixel data and RGBA values.
  - The lexer tokenizes commands sequentially on each line.

## 3. Game Engine & External Tool Interoperability
- **Unity 2021+ / 2022+ / 6:**
  - Native importer `Pix2UnityImporter.cs` reads `.pix2.json` export metadata.
  - Automatically slices spritesheet texture with exact pixel rects, pivots, and point filtering.
  - Generates `.anim` AnimationClips at the configured FPS.
- **Godot 4.x:**
  - Standard JSON atlas export maps directly to `SpriteFrames` resource.
- **Aseprite / PyxelEdit:**
  - PNG spritesheet export with 1px bleed protection spacing prevents color bleeding during bilinear or point scaling.
