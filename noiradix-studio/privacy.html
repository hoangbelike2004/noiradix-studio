Privacy Policy

Last Updated: November 7, 2026 • Effective Date: November 7, 2026
Core Privacy Guarantee: NOIRADIX Studio is a 100% client-side application. We do not operate tracking servers, we do not require account registration, and your pixel art files never leave your personal computer.

1. Information We Do Not Collect

Unlike traditional web applications, NOIRADIX Studio does not collect, transmit, store, or sell any personal data. Specifically:

  • No Personal Identifiable Information (PII): We do not ask for or collect names, email addresses, phone numbers, or passwords.
  • No Pixel Art or Project Data: Every sprite sheet, animation clip, palette swatch, and .pix2 document you create or edit is processed entirely in your web browser's local memory.
  • No Tracking Cookies: We do not set any advertising, profiling, or analytical tracking cookies.
  • No Server-Side Analytics: We do not run Google Analytics, Meta Pixel, Hotjar, or any commercial user session recording tools.

2. Local Storage and Browser Technologies

NOIRADIX Studio uses standard browser-native storage mechanisms solely to provide essential local functionality:

  • localStorage: Saves your chosen interface theme (Light or Dark mode), open workbench tabs, and the coordinates of the draggable floating about bubble. This data remains strictly on your local machine.
  • IndexedDB: When you grant explicit permission to open or save local files via the browser's File System Access API, temporary file handles are retained locally so you can continue your editing session across page reloads.
  • Crash Recovery Snapshot: A local backup snapshot of your active canvas is retained in browser storage so work is not lost if the browser tab is accidentally refreshed or closed.

3. Local File System Access API

NOIRADIX Studio utilizes the W3C File System Access API to enable seamless local desktop-like file workflows (such as Ctrl+S to save directly to disk). You must explicitly grant permission before NOIRADIX Studio can read or write to any selected file. NOIRADIX Studio cannot access any file or folder outside of the explicit file you selected.

4. Children's Privacy (COPPA Compliance)

Because NOIRADIX Studio does not collect any personal data whatsoever, it is completely safe for developers and students of all ages, including children under 13.

5. Open Source Transparency

NOIRADIX Studio is open source under the Apache License 2.0. The entire source code is publicly auditable on GitHub at github.com/dotlinux26/noiradix-studio. You can inspect every line of code to verify our zero-tracking architecture.
