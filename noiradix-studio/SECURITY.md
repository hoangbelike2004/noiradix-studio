# Security Policy

## Supported Versions

NOIRADIX Studio is a client-side static web application with zero backend servers and zero external data transmissions.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

---

## Reporting a Vulnerability

If you discover a security vulnerability (such as an issue with File System Access API sandboxing, memory exhaustion via crafted `.pix2` payloads, or DOM sanitization vulnerabilities), please do **NOT** open a public issue.

### 🛡️ Recommended: GitHub Private Vulnerability Advisory
Please report the vulnerability directly and privately via GitHub:
👉 **[Submit a Private Security Advisory](https://github.com/dotlinux26/noiradix-studio/security/advisories/new)**

### ✉️ Direct Contact
Alternatively, you can contact the maintainer directly:
* **Maintainer:** Nguyen Duc Canh ([@dotlinux26](https://github.com/dotlinux26))
* **Email:** `0206canh@gmail.com`

Please include:
1. A clear description of the vulnerability and its potential impact.
2. Step-by-step instructions or proof-of-concept `.pix2` file to reproduce.
3. Your proposed remediation if available.

We will acknowledge receipt within 24–48 hours and coordinate a coordinated security disclosure.
