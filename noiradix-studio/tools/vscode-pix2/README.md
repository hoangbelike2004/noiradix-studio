# PIX2 Language Support for VS Code

Official syntax highlighting and language configuration for the **PIX2** format (Structured Pixel Art Language).

## Features

- **Syntax Highlighting**:
  - Directives (`@pix2`, `@meta`, `@grid`, `@palette`, `@cell`, `@frame`, `@animation`, `@animations`, `@end`)
  - Section Identifiers (`cell_0_0`, `walk_down`)
  - Hex colors (`#ffffff`, `#ffffff80`)
  - Coordinates & dimensions (`-5,-10`, `16x16`)
  - AI & Procedural primitives (`pixel`, `sym_dot`, `rect`, `line`, `fill`)
  - Properties & Palette mapping keys
- **Code Folding**: Fold/unfold sections effortlessly.
- **Auto-Closing**: Auto-close brackets `[]` and strings `""`.
- **Comment Toggling**: Toggle comments using <kbd>Ctrl</kbd> + <kbd>/</kbd>.
